## [Sol Pico Ala](https://play.google.com/store/apps/details?id=lococoi.solpicoala)

**Políticas de Privacidad de Sol Pico Ala**

Fecha de última actualización: 9 de mayo de 2026

La presente Política de Privacidad describe cómo Sol Pico Ala trata la información en relación con el uso de la aplicación, los servicios de publicidad y la actualización de contenidos.

1.  Recopilación de información:

    Sol Pico Ala no recopila, almacena ni solicita información de identificación personal (PII), tales como nombres, direcciones de correo electrónico, números de teléfono o datos de ubicación exacta del usuario.


2.  Conectividad y Actualización de Contenidos:

    La aplicación requiere acceso a Internet para las siguientes funciones:
    * Actualización de datos: La aplicación descarga archivos de configuración y valores en formato JSON alojados en servidores de terceros (GitHub) para garantizar que el contenido esté actualizado.
    * Tratamiento de metadatos: Al realizar estas solicitudes técnicas de descarga, el proveedor de hosting (GitHub) puede procesar metadatos estándar (como la dirección IP del dispositivo) de acuerdo con su propia Política de Privacidad. Sol Pico Ala no envía, vende ni comparte información del usuario con estos proveedores.

    Te recomendamos encarecidamente revisar el siguiente documento de GitHub para comprender cómo se maneja la información durante los procesos de actualizaciones.

    * [Política de Privacidad de GitHub](https://docs.github.com/en/site-policy/privacy-policies) (https://docs.github.com/en/site-policy/privacy-policies)

3. Publicidad de Terceros
    La aplicación no contiene anuncios ni integra kits de desarrollo (SDK) de redes publicitarias de terceros. No se realiza un seguimiento del comportamiento del usuario con fines comerciales.

4.  Descargo de Responsabilidad Gubernamental:

    Sol Pico Ala es una herramienta de desarrollo independiente y privado;
    * No representa a ninguna entidad gubernamental.
    * No está afiliada, autorizada ni vinculada oficialmente con ninguna institución pública o fuerza de seguridad.
    * El contenido proporcionado es de carácter informativo y no reemplaza la normativa legal o los canales de información oficiales del Estado.

5.  Modificaciones

    Nos reservamos el derecho de actualizar esta política para reflejar cambios en la funcionalidad de la aplicación o requisitos legales. Se recomienda revisar este documento periódicamente.

6.  Contacto:

     Si tienes alguna pregunta o inquietud sobre esta política de privacidad, puedes contactarnos a través de [lococoi@proton.me](mailto:lococoi@proton.me).
